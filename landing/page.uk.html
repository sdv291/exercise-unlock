Часті запитання

Чи можна змінити, скільки часу дає вправа?

Так: меню «Пуск» → «Налаштування Exercise Unlock», сторінка «Час». Там секунди за кожну вправу, мінімум для входу й максимум за раз, для всіх дітей або для кожної окремо.

Чи передаються відео або інші дані в хмару?

Ні. Відео з вебкамери обробляється лише на комп'ютері. З телефона через сервер ідуть тільки 17 точок тіла без картинки, і сервер нічого не записує.

Чи обов'язкова вебкамера?

Ні, підійде смартфон із браузером: на екрані блокування є QR-код. Для телефона потрібен інтернет, без нього працює лише вебкамера.

Чи може дитина обійти програму?

Служба працює від імені системи, і звичайний обліковий запис не може її зупинити. Головне, щоб у дитини не було прав адміністратора.

Чи можуть комп'ютером користуватися кілька дітей?

Так, з версії 1.5. Додайте їхні облікові записи на сторінці «Користувачі» в налаштуваннях: у кожного свої хвилини за повтор, дозволені години й зароблений час.

Як видалити програму?

«Параметри» → «Програми» → Exercise Unlock → «Видалити». Вхід через PIN-код та інші налаштування Windows повертаються, як були.
